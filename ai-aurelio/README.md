# AI_AURELIO

Aplicación Android derivada de OfflineGPT (shauryag2002/OfflineGPT, commit 11d34c5012673e817703e3b6416c28f9036b5602, licencia MIT incluida en el proyecto).

El ZIP contiene el proyecto completo: interfaz original, inferencia Qwen3-8B con llama.rn, agente CSV y exportación de documentos XLSX, DOCX, PPTX, PDF y TXT. La ofimática se activa al comenzar el mensaje con el nombre correspondiente; los demás mensajes conservan el chat normal.

El flujo de Actions compila ARM64 y ejecuta las pruebas mínimas. Su artefacto queda pendiente de firma privada, aplicada fuera de GitHub. No contiene claves de firma ni modelos descargados.

Paquete nuevo: com.aiaurelio.office. Versión: 1.0.0 (100).
